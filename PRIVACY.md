# Privacy Policy

_Last updated: 2026-08-27_

**Puck Around does not collect, store, or transmit any personal data.**

The whole game happens on one device, between the people holding it:

- **No data is sent to us.** Puck Around has no server, no account, no
  sign-in, no analytics, no advertising, and no third-party SDKs. We receive
  nothing.
- **No network access.** The app makes no network connections of any kind. It
  requests no network-related permissions.
- **What's stored locally.** Only the game's own settings (such as the last
  number of players), kept in the app's standard local storage so they persist
  between launches. Deleting the app removes them.
- **No tracking.** The app does not track you across apps or websites and does
  not use any device identifiers for advertising.
- **Children.** Because the app collects no data at all, it collects none from
  children either.

## Verifying any of this

Puck Around is open source under the MIT license. Every claim on this page can
be checked in the code at <https://github.com/vlumi/puckaround> — the
entitlements file shows exactly which capabilities the app requests (none).
